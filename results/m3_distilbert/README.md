# M3 DistilBERT results

Generated by `python src/distilbert_model.py`; see
[docs/M3_DISTILBERT.md](../../docs/M3_DISTILBERT.md) for setup and protocol.

| File | What it contains |
| --- | --- |
| `validation_metrics.json`, `validation_predictions.csv` | Inner-training checkpoint selected on the training-only validation split. |
| `test_metrics.json`, `test_predictions.csv` | Held-out test scores and per-review probabilities for the final model. |
| `history.csv` | Per-epoch loss and validation scores used for early stopping. |
| `run_metadata.json` | Arguments, split counts, selected epoch, package versions, and timings. |

The final model is saved under the git-ignored `models/distilbert/` directory.
`test_predictions.csv` uses the same test id order as
`results/test_predictions.csv`, so the two files can be joined on `Id`.

Validation scores select the model and epoch; the test split is scored once
after selection. Do not use the test scores to choose hyperparameters.
