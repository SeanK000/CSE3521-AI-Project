# M3 data verification

`data_audit.json` is generated by `python src/prepare_m3_data.py` and records
the original source hashes, split counts, feature dimensions, rule coverage,
training-only examples, and software versions.

`verification.json` is generated by `python src/verify_m3_data.py`. This run
verified all 19 artifact checksums and all rows of all four saved feature sets,
and confirmed the original M2 test IDs, labels, and order. Nine unit tests also
passed (`python -m unittest discover -s tests -v`).

These are data/feature checks, not new model performance results. No classifier
training or held-out test scoring was performed. See
`docs/M3_DATA_ENGINEERING.md` for reproduction and role handoff.
